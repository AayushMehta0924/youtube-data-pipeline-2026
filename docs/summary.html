Day One: The Data Factory

You just joined the data team. Nobody expects you to know AWS yet — so before touching a single service, let's walk the whole factory floor together, room by room.

Your manager walks you to a whiteboard and says: "We want to know what's trending on YouTube — which videos, channels, and categories are winning, across 10 countries. Build me a factory that figures that out, automatically, every few hours, forever." That's the whole assignment. Let's tour the factory you're about to help run.

ROOM 01

The Warehouse

Before anything can be processed, you need somewhere to put raw stuff. So step one: you rent a warehouse — not a small one, an infinite one, where you only pay rent on the shelf space you actually fill.

You don't dump everything in one pile, though. You mark out three loading bays: Bronze (raw, untouched, exactly as it arrived), Silver (cleaned and organized), and Gold (finished, ready-to-sell product). This three-bay layout has a name in the trade — medallion architecture — but really it just means "never mix raw material with finished product."

Nameplate Amazon S3
ROOM 02

The Trucks Arrive

Two trucks pull up to the Bronze bay. Truck 1 is a one-time historical delivery — someone already collected years of old YouTube data and drives it in once, using a hand-written delivery slip (a script that just says "copy this file here," twenty times over).

Truck 2 never stops. Every few hours, a robot driver wakes itself up on a schedule, drives to YouTube's front desk, asks "what's trending right now, in each of these 10 countries?", and drives the answer straight into the Bronze bay as raw files.

Neither truck gets past the gate without an ID badge — a system that says exactly which shelves that robot is allowed to touch, and nothing more. No badge, no entry.

Nameplate AWS Lambda · Amazon EventBridge · AWS IAM
ROOM 03

The Labeling Robot

Now you've got hundreds of raw crates sitting in Bronze, and nobody labeled them. If someone asks "how many videos do we have for India?" you'd have to physically open every crate. Painful.

So you deploy a labeling robot that walks the aisles, peeks inside, and writes down what it finds — column names, row counts — onto one shared clipboard everyone in the factory can read.

Because that clipboard exists, anyone can now walk up with a query terminal and just ask questions in SQL — "show me videos from Canada" — without moving a single crate. It doesn't store anything itself; it just reads straight off the shelf using the clipboard as a map.

First inspection

You try this on the raw crates and — yikes. Dates are formatted like 17.14.11, some titles are missing, and the JSON crates are nested so oddly the terminal can't even read them yet. Classic raw data. On to the cleaning floor.

Nameplate AWS Glue Crawler · AWS Glue Data Catalog · Amazon Athena
ROOM 04

The Cleaning Floor

Two stations run at the same time, because they handle different-sized jobs. Station A, the small-parts bench: category-name files are tiny and simple, so one nimble worker unpacks them, removes duplicates, and repacks them as Parquet — a compact, organized crate format that's much faster to search than loose JSON or CSV.

Station B, the industrial line: the actual video statistics are huge, messy, and arrive in two different shapes — an old format and a new live one. This needs real machinery: a serverless big-data engine that chews through massive files in parallel, without you ever buying or babysitting a single server. It figures out which shape a file is, renames columns to match, fixes the ugly dates, drops duplicate videos, fills in missing numbers, and calculates new stats like "engagement rate."

Both stations write into the Silver bay in tidy Parquet, and update the shared clipboard themselves as they go — nobody has to send the labeling robot back around.

Nameplate AWS Lambda · AWS Glue (PySpark)
ROOM 05

The Quality Inspector

Before anything leaves Silver, it passes through a strict inspector's booth. The inspector pulls a sample and asks five questions: Is there enough data? Are important fields missing too often? Are all the expected columns even there? Do the numbers make sense — a video can't have negative views. Is this actually recent, or stale?

If something's off

The inspector pulls a fire alarm that instantly emails the team, saying exactly what failed and why — and critically, the line stops there. Bad data never reaches the next room.

Nameplate AWS Lambda · Amazon Athena · Amazon SNS
ROOM 06

The Packaging Floor

If quality passes, the clean material moves to final assembly — same kind of industrial machine as Room 04, but this time its job isn't cleaning, it's combining and summarizing into three finished products: a daily digest per country, a channel leaderboard ranked by region, and a category market-share report.

These land in the Gold bay as Parquet, auto-registered on the clipboard — ready for business use.

Nameplate AWS Glue (PySpark)
ROOM 07

The Storefront

Now anyone in the company can walk up to the counter. Analysts run SQL directly on Gold tables through the same query terminal from Room 03. Executives who'd rather not write SQL get a drag-and-drop dashboard sitting on top of that same data. Same product, different counters.

Nameplate Amazon Athena · Amazon QuickSight
ROOM 08

The Foreman

None of the above happens because someone manually walks to each station and presses start. That's the foreman's job. The foreman holds a clipboard with the exact plan: tell the truck robot to fetch new data → wait ten seconds for the warehouse system to catch up → send both cleaning stations at once, since neither needs the other → once both finish, call the inspector → inspector says pass, send it to packaging; inspector says fail, ring the alarm and stop → packaging finishes, ring the "all clear" bell.

If any single step breaks, the foreman doesn't just crash — it retries a couple of times automatically, and if it still fails, it rings the right alarm for that specific failure, so whoever's on call knows exactly which station broke without digging through logs. Every worker in the building — Lambda, Glue, the foreman itself — also keeps a running logbook of everything it did, in case someone needs to investigate later.

Nameplate AWS Step Functions · Amazon CloudWatch
ROOM 09

The Archive

One more room you haven't seen: old Bronze crates nobody's touched in 90 days don't need to keep paying warehouse-shelf prices forever. A standing rule automatically moves them into a deep archive vault — much cheaper rent, slower to retrieve, perfect for "we probably won't need this, but compliance says keep it."

Nameplate Amazon S3 Glacier
Shift summary

Trucks bring raw YouTube data in → a robot labels it → cleaning stations fix and organize it → an inspector checks it's good → a packaging floor turns it into three business reports → a storefront lets people query or view it → a foreman runs the entire building on autopilot → old stuff gets archived. That's the whole factory.
